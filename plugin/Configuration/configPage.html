Composer Shared Metadata

This plugin stores edited composer biographies and portraits in an independent SQLite database. It does not alter Jellyfin's native People or music database.

Use the Composer Browser Music tab to edit records. Jellyfin's Dashboard > Plugins > My Plugins manages enable/disable/uninstall. Dashboard > Plugins > Repositories manages the catalog URL separately.

Plugin health API: /ComposerSharedMetadata/health

Plugin activity appears in the standard Jellyfin logs with event prefix CSM. Normal log level reports plugin initialization, record-list requests, successful SQLite saves and revision conflicts. Enable Debug for Jellyfin.Plugin.ComposerSharedMetadata for additional diagnostics.

Backups: back up the ComposerSharedMetadata folder under Jellyfin's plugin configurations path before upgrades or removal.
